# Блиц — быстрые шахматы

Демо-лендинг для быстрой игры в шахматы: выбираешь время и играешь с компьютером прямо на странице. Чистые HTML, CSS и JavaScript, без зависимостей и сборки.

## Что умеет

- режимы по времени: 1+0, 3+2, 5+0, 10+0, часы с добавлением секунд и поражением по времени
- три уровня соперника (поиск с альфа-бета отсечением, глубина 1–3 хода и перебор взятий)
- все правила: рокировка, взятие на проходе, превращение пешки, мат, пат, ничья по повторению, правилу 50 ходов и недостатку материала
- подсветка легальных ходов, последнего хода и шаха, запись партии в SAN (`Nf3`, `exd5`, `O-O`, `Qxf7#`)
- отмена хода, переворот доски, сдача, выбор цвета
- адаптив и `prefers-reduced-motion`

## Как устроен код

`app.js` состоит из трёх частей: правила (позиция, генерация ходов, нотация), соперник (negamax) и интерфейс. Движок сверен с эталонными числами перфт для начальной позиции, Kiwipete и ещё двух сложных позиций.

## Запуск

Открыть `index.html` или `python3 -m http.server`.
